# Asman Hudaykulyyev — portfolio

A static personal portfolio for software and business automation work. GitHub Pages serves the files in this repository's root from `main`; there is no build step or dependency installation.

## Edit the site

- `index.html` contains the content and metadata.
- `style.css` contains the design and responsive styles.
- `favicon.svg` is the site icon.
- `photo_2026-03-26_20-13-13.jpg` is the portrait in the About section.

Project descriptions should stay specific about the problem, contribution, and current state. The original Gemini summary is local research material and is ignored by Git along with `meme.jpg`.
